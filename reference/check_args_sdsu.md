# Check arguments for Static and Dynamic Substance Use (SDSU) scores functions

Validates the arguments to compute a SDSU score.

## Usage

``` r
check_args_sdsu(data = data, name = name)
```

## Arguments

- data:

  tibble. Input data frame to validate.

- name:

  character(1). Name of the output score column to validate.

## Value

invisible NULL. Throws an error if checks fail.
