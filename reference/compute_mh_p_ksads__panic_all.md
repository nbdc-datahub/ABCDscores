# Compute all summary scores for mh_p_ksads\_\_panic

This function computes all summary scores for the mh_p_ksads\_\_panic
table. Make sure to have all necessary columns in the data frame.

## Usage

``` r
compute_mh_p_ksads__panic_all(data)
```

## Arguments

- data:

  tbl. Data frame containing the columns to be summarized.

## Value

tbl. The input data frame with the summary scores appended as new
columns.
