# Compute all summary scores for mh_p_ksads\_\_socanx

This function computes all summary scores for the mh_p_ksads\_\_socanx
table. Make sure to have all necessary columns in the data frame.

## Usage

``` r
compute_mh_p_ksads__socanx_all(data)
```

## Arguments

- data:

  tbl. Data frame containing the columns to be summarized.

## Value

tbl. The input data frame with the summary scores appended as new
columns.
