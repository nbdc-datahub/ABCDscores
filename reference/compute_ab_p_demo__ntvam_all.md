# Compute all the ab_p_demo\_\_ntvam scores

A single function to compute all scores in the above domain using
**default** arguments.

## Usage

``` r
compute_ab_p_demo__ntvam_all(data)
```

## Arguments

- data:

  tbl, Dataframe containing the columns to be summarized.

## Value

tbl. The input data frame with the summary scores appended as new
columns.
